BRAINROT BASE RUSH is a 3D Roblox tycoon game about absurd Indonesian brainrot characters -- Bambang Blender, Siti Spatula, Ratu Rice Cooker, Pak Haji Helicopter and fifteen more -- who wander a central lane waiting to be caught. Touch one to catch it, carry it home to a pad at your base and it earns Cash every second; rarities run Common to Brainrot God, with Gold, Diamond and Rainbow mutations multiplying income. Spend Cash on eggs at the shop stall, run home when the tsunami warning sounds (get caught outside your base and your catch washes back to the wild), chase off the Maling Bot who steals your best pad brainrot, and rebirth for a permanent +100% income multiplier per rebirth.

## Run it

Rojo project: build the place with `rojo build default.project.json --output game.rbxl`, open game.rbxl in Roblox Studio to play, and package the entry with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
